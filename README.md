# PaveVision AI

AI-powered smart road infrastructure monitoring platform using YOLOv8 for pothole detection, GPS mapping, analytics, and live surveillance.

## Features

- Real-time pothole detection
- Severity classification
- GPS monitoring map
- Live AI surveillance
- Detection analytics dashboard
- Detection logs and reporting

## Tech Stack

- Python
- Flask
- YOLOv8
- OpenCV
- MySQL
- Leaflet.js
- HTML/CSS/JavaScript

## Setup Instructions

```bash
pip install -r requirements.txt
python app.py
